# Third-party components

This project uses dependencies with their own licenses. The lockfile pins exact versions.

- Three.js: MIT, copyright three.js authors. Its complete license is installed at `node_modules/three/LICENSE`. Used for 3D rendering and an independent reference implementation in tests; the production BVH parser and pose evaluator are original code.
- Electron: MIT with Chromium and other bundled third-party notices. The unpacked Windows distribution contains `LICENSE` and `LICENSES.chromium.html`. Preserve these files when redistributing an unpacked build. A portable EXE retains the embedded distribution.
- Manrope: SIL Open Font License 1.1, copyright Manrope Project Authors. Installed through `@fontsource-variable/manrope`; its OFL license is bundled by the project.
- Vite: MIT, development/build dependency.
- electron-builder: MIT, development/packaging dependency.

The built-in `public/samples/procedural-walk.bvh` is generated by this project's `scripts/generate-demo.mjs` and is licensed under this project's MIT license. It is synthetic motion, not a recording.

The course slides and original BVH files supplied by the user are **not distributed in this repository or executable**. They are used locally for compatibility checks only.
