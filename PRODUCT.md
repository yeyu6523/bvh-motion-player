# BVH Motion Player

<!-- impeccable:product-schema 1 -->

## Platform
web

Electron wraps the local web renderer into a Windows desktop EXE.

## Stack
User prefers a Windows EXE rather than a browser-only deliverable. Implementation: JavaScript, Three.js, Electron. Engine choice is delegated within the requirement to work outside the original MFC environment.

## Users
Students and reviewers demonstrating a BVH motion-capture programming assignment.

## Product Purpose
Open a BVH file, display its articulated skeleton, play, pause, and adjust playback speed.

## Capabilities and Constraints
- Publish the complete, uncompressed project in a public code repository.
- Provide an optional Windows executable separately; no unitypackage or archive-only source submission.
- Do not publish the user's course slides or supplied motion files. Use those locally for validation only.
- Keep the app offline after installation and process files locally.

## Evidence on Hand
The user supplied BVH文件解析.ppt and eleven BVH recordings. The slides describe hierarchical offsets, declared channel order, and time-based animation.

## Open Decisions
No visual identity was specified. The interface should prioritize classroom demonstration and legibility.
